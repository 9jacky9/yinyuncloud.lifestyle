隐私政策 (Privacy Policy)

绝不妥协的无痕隐私保障，守卫您的每一次数字视听之旅

1. 明确承诺：不留存任何用户网络活动日志

隐云机场恪守最严格的“零活动日志”（No-Activity-Logs）准则。在您使用本服务的任何环节中，我们绝不记录、绝不追踪、绝不向任何第三方转交您的任何网络轨迹。

具体而言，我们保证在技术架构上不会收集：

  • 您浏览的网站地址、流媒体观看片单或 API 访问请求；
  • 您在网络传输中的原始数据负载、会话正文或任何个人偏好；
  • 您发起连接时使用的本地物理 IP 地址与地理定位信息；
  • 您每次会话的具体起止时间戳。

2. 纯内存架构与会话即焚机制

隐云机场的全部边缘节点均配置了“纯 RAM 内存系统”。这意味着所有数据转发行为均在临时高速内存中即时完成，没有物理硬盘写入权限。当数据包发送完毕后，内存中相关临时句柄被立即覆写抹除。服务器在发生常规运维重启或电源断开时，所有运行痕迹永久消融，从根源上杜绝了数据被事后恢复的可能性。

3. 最小化账户信息管理

我们仅在中心用户数据库中保存维持服务运营所必须的极简信息：

  • 注册电子邮件：仅用于账号找回及紧急服务通告，支持使用匿名邮箱；
  • 周期流量计量器：仅记录当前套餐所消耗的总字节数值（纯数字，无访问细节），用于配额管理；
  • 订阅有效期：仅用于计算套餐起止日期。

4. 密码学加密安全标准

所有在您的终端设备与隐云服务器之间传输的通信流量，均受到高强度端到端密码学协议的严密封装保护。即使处于公共 Wi-Fi 或不安全的网络环境中，任何第三方网络监听者也只能看到不可解密的混淆流，完全无法窥探通信内容。
